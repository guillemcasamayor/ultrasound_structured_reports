# Ultrasound Structured Reports

Repositorio de informes estructurados HTML de ecografía.

- **GitHub Repository**: [https://github.com/guillemcasamayor/ultrasound_structured_reports](https://github.com/guillemcasamayor/ultrasound_structured_reports)

## Informes disponibles
- `ecografia_tiroides_tirads.html` — Informe estructurado de ecografía tiroidea y calculadora ACR / EU-TIRADS.
- `ecografia_renovesical.html` — Informe estructurado renovesical.
- `ecografia transfontanelar.html` — Informe estructurado de ecografía transfontanelar.
- `ecoespatlla.html` — Informe estructurado ecografía de hombro.
- `modulo_elastografia_canon_v5.html` — Módulo de elastografía hepática Canon.
